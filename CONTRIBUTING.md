# Contributing

Use focused branches and pull requests. Preserve unrelated work and recorded owners.

Run the documented tests, exercise the browser's actual import/edit/play/export path, and retain exact source and results. Arithmetic tests do not establish musical quality. Inspect actual waveforms and listen to the rendered output.

Never treat an incomplete search as proof that no arrangement exists. Keep imported audio and credentials out of commits. No automatic model calls, cloud deployment or publication is part of opening the local application.
