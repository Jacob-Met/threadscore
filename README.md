# THREADSCORE

A relationship score for persistent musical motifs. This is owner-selected concept 6 in [HAMON #1631](https://github.com/Jacob-Met/hamon/issues/1631#issuecomment-6431104215), claimed by the retained estate-08e93e team in [the native work thread](https://github.com/Jacob-Met/hamon/issues/1631#issuecomment-6431227633).

Development is beginning in an isolated private branch. The goal is an actual symbolic composition instrument: edit three motifs, connect their occurrences with musical relationships, preserve locked notes, inspect and audition proposals, and export MIDI, stems, and an editable score. Real NVIDIA-model program synthesis on authorized Nebius infrastructure remains an explicit requirement and currently unverified dependency.

This is a new implementation of the selected direction. Retired CUELOOM source remains separately preserved and is not being relabeled.
